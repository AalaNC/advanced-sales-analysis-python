# 📊 Advanced Sales Analysis with Python

## 📌 Descripción del Proyecto

Este proyecto consiste en un análisis avanzado de ventas utilizando Python, pandas, matplotlib y seaborn para explorar el comportamiento del negocio, identificar patrones de ventas, analizar rentabilidad y detectar oportunidades de mejora.

El análisis incluye KPIs, visualizaciones avanzadas, análisis temporal y correlaciones entre variables para obtener insights de negocio relevantes.

---

## 🔍 Objetivos del Proyecto

Durante el análisis se buscaron responder las siguientes preguntas:

* ¿La empresa es rentable?
* ¿Qué categorías generan mayores ganancias?
* ¿Cómo evolucionan las ventas a lo largo del tiempo?
* ¿Qué impacto tienen los descuentos sobre la rentabilidad?
* ¿Existen patrones o estacionalidad en las ventas?
* ¿Qué productos generan mayores ganancias y pérdidas?
* ¿Qué relaciones existen entre las variables numéricas?

## 🧠 Insights Principales

* La categoría Tecnología presenta las mayores ventas y ganancias.
* Furniture presenta un margen de ganancia muy bajo.
* Los descuentos elevados generan pérdidas significativas.
* Existe una correlación negativa entre Discount y Profit.
* Las ventas presentan comportamiento estacional.
* Algunos productos generan pérdidas importantes para la empresa.

---

## 📅 Análisis Temporal

El análisis temporal permitió identificar:

* Incremento general de ventas a lo largo del tiempo
* Meses con mayores ventas como febrero, agosto, octubre y noviembre
* Patrones repetitivos de comportamiento en distintos años
